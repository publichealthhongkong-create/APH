# 香港公共健康協會 — 官方網站

現代化、響應式及無需建置的六頁非牟利機構網站，以「專業、溫暖、可信」為設計核心。

## 頁面

| 檔案 | 內容 |
| --- | --- |
| `index.html` | 主頁：首屏、核心數據、三大服務、機構故事、最新動態 |
| `about.html` | 協會簡介：成立背景、價值觀、里程、核心團隊、慈善資質 |
| `support.html` | 六項支援計劃、可篩選卡片、申請流程、保密說明 |
| `courses.html` | 跆拳道九區據點、輔導心理學服務、中醫講座與轉介、FAQ |
| `prevention.html` | 五種常見疾病預防指引、公共衛生危機防範、疫苗資訊 |
| `contact.html` | 義工電郵登記、聯絡資料及快速聯絡分類 |

## 設計與功能

- **設計語言**：深海藍、薄荷綠、珊瑚橘與暖杏色；純白／極淺灰背景配深石墨灰文字。
- **響應式編排**：桌面、平板及手機版；固定置頂導航及全屏流動選單。
- **互動細節**：滾動進場、計劃分類篩選、FAQ 摺疊、返回頂部、鍵盤焦點管理及 reduced-motion 支援。
- **無外部執行依賴**：所有圖片、CSS、JavaScript 及圖示均存放在本專案內；只有電郵連結會離開網站。
- **無障礙**：跳至主要內容連結、語意標記、可見焦點、ARIA 狀態及替代文字。
- **官方標誌**：頁首使用機構標誌圖案配機構名稱；頁尾使用淺色版本完整標誌。

## 預覽

在專案資料夾執行任何靜態伺服器即可，例如：

```bash
python3 -m http.server 8000
```

然後開啟 `http://localhost:8000/`。

直接雙擊 `index.html` 亦可瀏覽，但使用本機伺服器可獲得更一致的路徑體驗。

## 義工與聯絡說明

- 義工參與不設網上表格；有意者可直接電郵 `enquiry@publichealth.org.hk`，並在郵件註明姓名、聯絡方法、年齡組別、服務意向及可參與時段。
- 電子通訊訂閱會以 `mailto:` 開啟使用者的郵件應用程式，不會把個人資料儲存在網站。
- 地址以文字方式呈現，不嵌入任何地圖服務。
